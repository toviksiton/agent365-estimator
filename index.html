Understanding Agent 365 Costs

Your agent has two cost components: a fixed governance license + variable costs per activity.

💡 Key Principle: Whether 1 or 10,000 people use your agent, you pay per activity. User count doesn't matter—activity volume does.

Cost Breakdown

  • Agent 365 License ($15/mo): Governance rights for your agent owner. Fixed cost, never changes.
  • Work IQ API: Charges per call to access M365 data (~0.1 credits = $0.001)
  • Copilot Studio: Charges per response (1–5 credits = $0.01–$0.05 depending on complexity)
  • Foundry Compute: Optional—only if using custom hosted agents ($0.15/vCPU-hour avg)

Frequently Asked Questions

Do I pay for Agent 365 even with zero activity?

Yes. The $15/month is your governance license—the right to build and own agents. It's independent of usage, like a subscription.

Can multiple agents share one Agent 365 license?

Yes. One Agent 365 owner ($15/month) can govern many agents. The cost is per-governor, not per-agent.

Why scale by activity, not users?

Each response calls Work IQ and Studio (metered per call). 1 user × 100 calls = 100 users × 1 call. Same cost either way.

What's the minimum monthly cost?

$15/month (Agent 365 alone). Zero activity = zero variable costs, but you always pay the governance license.

How cheap are activities?

Very. Simple Q&A = $0.011. Run 1,000 Q&As for $11. Even 50,000 activities/month = $500–800 variable + $15 fixed.

What about Foundry Hosted Agents?

Scale-to-zero: pay only when active. Idle time = $0. Budget 0.5–2 vCPU-hours per 1,000 activities.

Can I negotiate pricing?

These are public list prices. Enterprise agreements handled by your Microsoft CSP. Contact them for custom quotes.

How to measure actual costs?

Monitor M365 Admin Center > Copilot Credits dashboard daily. Track API calls and Studio responses. Compare pilot vs. estimate.
