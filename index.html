🚀 How This Works

Your Agent 365 autopilot incurs two types of costs: fixed governance licences and variable AI consumption. Here's the breakdown:

📌 Fixed Costs: Governance & Licensing

The Agent 365 licence ($15/month) is required per agent owner. It covers governance, lifecycle management, policy enforcement, and access control—not per-activity runtime charges.

⚡ Variable Costs: AI Activity Consumption

Each autopilot action consumes different amounts of Work IQ API calls and Copilot Credits depending on complexity:

Q&A: Simple knowledge retrieval ($0.011/call)

Work IQ API lookup + 1 Copilot response = ~1.1 credits

Cheapest

Summarization: Email or document analysis ($0.025/call)

Work IQ search + content extraction + Copilot synthesis = ~2.5 credits

Moderate

Drafting: Email composition ($0.042/call)

Context retrieval + multi-turn reasoning + Copilot draft = ~4.2 credits

Higher

Documents: Full document creation ($0.066/call)

Deep analysis + template selection + structured generation = ~6.6 credits

Premium

💡 Key Insight: Work IQ API (0.1 credit/call) is your biggest cost driver, typically 85–90% of variable consumption. Every action queries Microsoft 365 data.

❓ Frequently Asked Questions

Do I need Agent 365 even if nobody uses the agent?

Yes. The $15/month Agent 365 licence is a governance and platform fee per agent owner, required regardless of usage. Think of it as your "enterprise seat" for the Autopilot platform. Variable costs scale with activity, so an idle agent costs only $15/month.

What's the difference between Work IQ API and Copilot Credits?

Work IQ API searches your M365 data (0.1 credits per call). Copilot Credits are used for AI reasoning and response generation. Most activities combine both: search your data (Work IQ) + generate an answer (Copilot).

Can I estimate Foundry compute costs?

Yes, but they're optional. If you host your agent in Foundry, you pay only for active vCPU-hours. A small agent running 5 hours/day averages ~$22/month. Check the calculator's "Advanced Options" to include this.

Are these prices locked in or subject to change?

These are official Microsoft public list prices as of October 2026. Volume discounts and multi-year agreements may apply. Contact your Microsoft account manager for enterprise pricing.

Can I get a per-agent runtime fee instead of per-owner?

No. Agent 365 is licensed per user (owner), not per agent. If one owner manages multiple agents, you need only one $15 licence.

What costs am I NOT paying?

You're not charged for: storage (M365 owns your data), API latency, policy enforcement, or access control. You pay only for active AI consumption (Work IQ + Copilot) and governance.
